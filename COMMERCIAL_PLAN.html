What is Sentra?

A distributed data processing platform that executes pipelines where data already lives — on customer infrastructure, at the edge, or on-premise. Agents process data locally and push only results.

No data egress. No per-row pricing. No vendor lock-in.

Core Thesis

The market is saturated with tools that charge by data volume moved. Sentra's differentiation is charging by compute capacity — not data throughput. This aligns incentives with customers who want predictable costs and data sovereignty.

Current State

The platform is fully built — multi-tenant architecture, 55+ edge functions, 51 database tables, complete dashboard UI, agent fleet management, pipeline execution engine, plugin system, and security infrastructure. What's missing is the billing integration, paywall gating, and go-to-market motion.

Product Overview Section 2

What it Does

  • Register datasets from S3, Azure, GCS, or local mounts
  • Scan, chunk, and distribute processing across a fleet of agents
  • Run multi-step pipelines (scrape, transform, PII redact, merge)
  • Output results to configurable storage backends
  • Monitor fleet health, alert on failures, audit activity

Key Differentiators

  • Local processing: data never leaves customer infrastructure
  • Single binary agent: one command to install, three env vars
  • Plugin system: custom logic via WASM/JavaScript, signed & sandboxed
  • No data egress fees: processes in situ, pushes only results
  • Multi-cloud: S3, Azure Blob, GCS, MinIO, Cloudflare R2

Revenue Model Section 5

Primary: SaaS Subscription

Monthly or annual subscription for the Sentra control plane (dashboard, API, agent orchestration). Multi-tenant SaaS with on-premise option for Enterprise.

Secondary: Compute Credits

Pre-purchased blocks of agent compute time (agent-minutes or GB-processed). Captures value from heavy pipeline usage while keeping base subscription affordable.

Sentra's Competitive Moat

  1. Data gravity advantage: Processes where data lives — no egress, no transfer time, no compliance risk.
  2. Single-binary agent: curl -fsSL https://sentra.sh/install | bash — seconds to install.
  3. Plugin ecosystem: Custom processing in JS/WASM, signed and sandboxed. Marketplace potential.
  4. Multi-cloud by default: S3, Azure, GCS, MinIO, R2, NFS — no vendor lock-in.
  5. No data tax: Pricing by compute capacity, not data volume. Predictable bills.

Risks & Mitigations Section 10

Click each risk to view mitigations.

⚠️ Low Conversion: Free → Paid

▼

Likelihood: Medium

Free plan is generous (1 agent). Users may stay free indefinitely.

Mitigation: Show comparison banners. Add "Team-only" features (SSO, audit export, custom storage configs, 90-day history) that create genuine upgrade motivation.

😓 Churn Due to Complexity

▼

Likelihood: Medium-High

Developer-oriented product with learning curve. Non-technical users may struggle.

Mitigation: Improve onboarding wizard, sample pipelines, interactive tutorial, quickstart datasets. Monitor time-to-first-pipeline as core metric.

🆚 Competition from OSS Tools

▼

Likelihood: High

Airbyte, Prefect, dbt all OSS with large communities. Edge focus is a differentiator but not insurmountable.

Mitigation: Double down on "data sovereignty + edge processing" narrative. Open-source agent or plugin SDK to build community. Better UX than OSS alternatives.

🐌 Long Enterprise Sales Cycles

▼

Likelihood: Medium

Enterprise deals often take 6–12 months, starving early revenue.

Mitigation: Focus on self-serve PLG for first 6 months. Enterprise should be inbound-led (free → Team → Enterprise upgrade path).

🔗 Stripe + Supabase Vendor Lock-in

▼

Likelihood: Low-Medium

Both are well-established but increase dependency.

Mitigation: Abstract billing behind service layer. Supabase can be self-hosted (open-source). Keep billing logic in Edge Functions with clean interfaces.

🔐 Security & Compliance Burden

▼

Likelihood: Medium

Enterprise customers will demand SOC 2, HIPAA, GDPR compliance.

Mitigation: Start SOC 2 Type II in Year 1. Document data flows for GDPR. Offer on-premise control plane for regulated industries. Plugin signing keys already built.
